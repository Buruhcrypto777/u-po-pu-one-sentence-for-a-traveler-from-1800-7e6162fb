Entry for the make.fun bounty [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb).

A pure-stdlib Python program (`main.py`) writes one sentence to `/output/entry.txt` — explaining the modern internet to someone arriving from 1800, using only things a person from that year already knows:

> The internet is every library on earth folded into one room, where a letter to a stranger in China is answered before your tea cools.

133 characters. One true comparison carries the whole sentence: every library folded into one room (reading all knowledge), and a letter answered before your tea cools (writing to anyone, instantly). The program runs offline and produces byte-identical output on every run.
